# WeatherMe

Одностраничное веб-приложение с прогнозом погоды. Показывает текущую погоду в выбранном городе, прогноз на несколько дней вперёд и почасовой график температуры.

Написано на HTML, CSS и чистом JavaScript — без фреймворков, библиотек и сборки. Данные о погоде предоставляет [WeatherAPI.com](https://www.weatherapi.com/).

## Возможности

- **Поиск города.** Введите название в строку поиска и нажмите Enter.
- **Прогноз по дням.** Каждый день — отдельная карточка в слайдере: город, температура, иконка погоды, дата, влажность, видимость, давление и скорость ветра. Для сегодняшнего дня показана текущая погода, для следующих — минимальная и максимальная температура.
- **Навигация.** Между днями можно переключаться стрелками слайдера или вкладками Today и Tomorrow.
- **Почасовой график.** Температура и иконки погоды на выбранный день с шагом в 3 часа, с 1:00 до 22:00. Цвет графика зависит от температуры: от синего (холодно) через зелёный к красному (жарко).
- **Переключатель °C / °F.** Меняет единицы температуры на карточках и на графике.
- **Время обновления.** В шапке показано местное время последнего обновления данных.
- **Загрузка и ошибки.** Во время загрузки показывается анимация. Если запрос не удался (например, город не найден) или сервер не ответил за 10 секунд, появляется окно с ошибкой.

## Технологии

- HTML5, CSS3
- JavaScript (ES6+), запросы к API — через `XMLHttpRequest`
- SVG — для графика температуры
- Шрифты Poppins и Pacifico из Google Fonts
- [WeatherAPI.com](https://www.weatherapi.com/docs/), метод `forecast.json`

## Запуск

Устанавливать зависимости и собирать проект не нужно — достаточно любого локального сервера:

```bash
git clone https://github.com/darina-bal/weather.git
cd weather
python -m http.server 8000
```

Затем откройте в браузере <http://localhost:8000>. Вместо Python подойдёт расширение Live Server для VS Code.

Открывать `index.html` двойным кликом не стоит: по протоколу `file://` не загрузятся иконки погоды. Сервер запускайте именно из папки проекта — часть иконок подключена в CSS по путям от корня сайта (`/assets/images/...`).

## Ключ API

Ключ WeatherAPI указан в [assets/script/main.js](assets/script/main.js), в функции `loadDoc`. Чтобы использовать свой:

1. Зарегистрируйтесь на [weatherapi.com](https://www.weatherapi.com/) и скопируйте ключ из личного кабинета.
2. Подставьте его в параметр `key` в адресе запроса:

```js
xhttp.open("GET", `https://api.weatherapi.com/v1/forecast.json?key=ВАШ_КЛЮЧ&q=${inputText}&days=8`, true);
```

Приложение запрашивает прогноз на 8 дней (`days=8`), но сколько дней вернёт API, зависит от тарифа WeatherAPI.
